# Homebrew tap for λtext

```bash
brew install ltext/tap/ltext
```

This installs the prebuilt [ltext](https://github.com/ltext/ltext) release binaries, on macOS
(Apple silicon and Intel) and Linux (x86_64 and aarch64).

`Formula/ltext.rb` is generated by `bin/update-formula [TAG]` from a release's
`SHA256SUMS`. ltext's release workflow runs it and pushes the result for every
new tag. The workflow in this repository tests the formula on macOS and Linux
(`brew install`, `brew test`, `brew audit --strict`).
